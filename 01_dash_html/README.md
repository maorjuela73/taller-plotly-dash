# Módulo 1: Plantilla Dash y HTML Components

En este ejercicio aprenderás a maquetar tu primera página web analítica sin escribir HTML crudo, usando el submódulo `dash.html`.

## Conceptos Clave

* **Boilerplate de Dash:** Instancia `app = Dash(__name__)` y servidor local `app.run(debug=True)`.
* **Propiedad `children`:** Define qué elementos van anidados dentro de una caja contenedora.
* **Propiedad `style`:** Recibe un diccionario Python con nombres en camelCase (`textAlign`, `backgroundColor`).

## Tu Misión
