# Módulo 2: Dash Core Components (`dash.dcc`)

El módulo `dash.dcc` ofrece componentes interactivos (Dropdowns, Sliders, Inputs) y el contenedor `dcc.Graph` para visualizar gráficos de Plotly.

## Tu Misión

Abre `estudiante.py`, descomenta y completa los 3 retos para mostrar el selector desplegable, el control deslizante y el gráfico interactivo del dataset Iris.
