# Módulo 3: Decoradores y Callbacks Reactivos

Los **callbacks** son el motor reactivo que escucha los eventos del usuario (`Input`) y actualiza los componentes de destino (`Output`).

## Tu Misión

Abre `estudiante.py` y completa el decorador `@app.callback` y la función para que el texto escrito por el usuario actualice el mensaje en tiempo real.
