# Módulo 4: Proyecto Integrador (Dashboard Reactivo Completo)

En este proyecto final combinarás maquetación HTML, widgets `dcc`, y un callback con **múltiples entradas y múltiples salidas** usando el dataset socioeconómico Gapminder.

## Tu Misión

Abre `estudiante.py`, completa el callback para filtrar el DataFrame por continente y año, y retorna tanto el gráfico actualizado como el resumen estadístico.
